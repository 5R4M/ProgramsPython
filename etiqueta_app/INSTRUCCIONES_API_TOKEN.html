🔑 Cómo obtener tu API Token de PythonAnywhere

1 Ve a www.pythonanywhere.com e inicia sesión con tu cuenta
2 Haz clic en tu nombre de usuario (esquina superior derecha) y selecciona "Account"
3 Busca la sección "API token" en la página
4 Haz clic en "Create a new API token"
5 Copia el token generado (es una cadena larga de letras y números)
6 Pégalo en el programa cuando te lo solicite

⚠️ Importante: Guarda tu API Token en un lugar seguro. No lo compartas con nadie.
